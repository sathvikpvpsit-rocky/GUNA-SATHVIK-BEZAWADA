# **App Name**: ConnectFolio

## Core Features:

- User Profile Management: Enable users to securely input, update, and manage their personal information, experience, education, projects, and skills through an administrative interface.
- Dynamic 'About Me' Section: Showcase a detailed 'About Me' section dynamically generated from user input, covering professional summary, experience history, and educational background.
- Interactive Project Portfolio: Display a customizable portfolio of projects, each with detailed descriptions, screenshots/previews, and external links to live demos or code repositories.
- Skills and Technologies Display: Present a clear and categorized section enumerating the user's proficiency in various technical skills and tools.
- AI Content Enhancer Tool: Provide an AI-powered tool to help optimize 'About Me' statements and project descriptions for conciseness and impact, tailored for recruiter engagement.
- Contact & Resume Gateway: Feature prominent call-to-action elements for direct contact via a form or email, and a secure download link for the user's resume.

## Style Guidelines:

- Primary color: A deep, professional navy blue (#264073), conveying stability and trust.
- Background color: A very light, subtle bluish-gray (#F0F1F5), offering a clean and modern canvas.
- Accent color: A vibrant yet elegant medium purple (#8566CC), for interactive elements and highlights to draw attention.
- Body and headline font: 'Inter' (sans-serif) for its modern, neutral, and highly readable qualities, supporting the minimalist theme.
- Use a set of professional, clean line icons that complement the modern and minimalist aesthetic.
- Implement a responsive, grid-based layout with generous white space, ensuring content breathability and focus across all devices.
- Incorporate subtle hover effects on interactive elements and smooth transitions for section scrolling, enhancing user experience without being distracting.
